# Rock-Paper-Scissors Game

Welcome to the **Rock-Paper-Scissors** repository! This project features a command-line Python program that allows you to play the classic game against the computer. It's a fun way to demonstrate Python basics, randomization, and conditional logic.

## 🔧 Technologies and Tools Used
This project was developed using Python and includes:

1. **Random Module**: To generate random choices for the computer.
2. **Control Structures**: To manage the game logic and determine the winner.
3. **User Input/Output**: For interacting with the player and displaying results.

## 🌐 Program Overview
The script enables users to play Rock-Paper-Scissors against the computer with the following features:

- Player chooses between rock (0), paper (1), or scissors (2).
- Computer randomly selects its move.
- The winner is determined based on standard game rules:
  - Rock beats scissors.
  - Paper beats rock.
  - Scissors beats paper.
  - Same choices result in a draw.
- Clear visual feedback for each round, including player and computer choices, and the game result.
- Robust handling of invalid inputs with prompts to retry.

## 🚀 How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/notfawadmir/Rock-Paper-Scissors.git
   ```

2. Navigate to the repository folder and run the script:
   ```bash
   python rock_paper_scissors.py
   ```

3. Follow the on-screen prompts to:
   - Enter your choice (rock, paper, or scissors).
   - View the computer's choice and the round's result.

4. Play multiple rounds and enjoy the game!
